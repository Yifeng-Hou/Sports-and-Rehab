三、逻辑链

1. 为什么是冈下肌/小圆肌肌腱病？

排球扣球、发球、拦网等动作，使肩后袖肌群反复承受：

· 外旋向心收缩；
· 外展末端和减速阶段的离心制动；
· 肩外展90°附近的反复负荷。

长期累积导致冈下肌/小圆肌肌腱退变、胶原排列紊乱、微小损伤，形成肌腱病。它不是一次性撕裂，所以病程可以长达数月甚至更久。

2. 各动作的疼痛解释

动作 机制
外展0°、体前静态抗阻外旋痛 冈下肌/小圆肌处于相对缩短位强力收缩，病变肌腱附着点受到集中牵拉应力
外展90°非痛弧区抗阻外旋不痛 肌腱被预先拉长，受力更均匀，且未进入机械挤压窗口
招财猫后摆极限痛（极度外旋） 大结节向后上方旋转，冈上肌后束肌腱被挤入肱骨头与后上关节盂缘之间；冈下肌/小圆肌腱也被极限牵拉
招财猫前摆极限痛（极度内旋） 冈下肌/小圆肌肌腱被拉长到接近极限，产生牵拉痛；不是肩胛下肌撞击
前摆越过一定范围后疼痛减轻 到达关节囊/韧带锁定位后，肱骨运动停止，肌腱不再被继续拉长，牵拉刺激从峰值回落；不是“卡压解除”
背后双手互抓痛且受限 盂肱关节极度内旋并内收，冈下肌/小圆肌肌腱被牵拉至最大长度
外展180°末端痛 末端关节被动阻力增大，肩后袖需强力收缩稳定肱骨头，病变肌腱承受高负荷

3. 卡压机制：为什么是“后上盂缘”，不是“肩胛冈下方空隙”？

招财猫极度外旋位时，肱骨大结节向后上方旋转，把肩后袖肌腱卷向后上关节盂缘。

· 肩胛冈根部构成这个狭窄空间的后上边界，像“天花板”；
· 但真正造成点状、锐利压迫的，是后上关节盂缘这个“台阶”；
· 肱骨头像拳头，把有病的肌腱碾在盂缘上；
· 冈盂切迹容纳肩胛上神经血管，偏内侧，通常不是这个动作的直接卡压点。

所以，患者感觉“三角肌深处”痛，是因为病变肌腱和撞击点位于三角肌后束/中束覆盖的深层。

4. 为什么病程长？

这不是急性肌肉拉伤，而是慢性肌腱病。肌腱病没有“几周自愈”的规律，只要排球负荷和动作模式不变，就会在特定力学条件下反复被激活。

误解3：把三角肌后束拉伤作为首选

· 问题：动作解释力很强，但“长期存在”不符合急性肌肉拉伤的恢复周期。
· 修正：不是急性拉伤，而是三角肌后束深面的冈下肌/小圆肌肌腱病或激痛点。

误解4：把“体前静态抗阻外旋”误当成Empty Can测试

· 问题：曾把外展0°抗阻外旋与冈上肌的Empty Can测试混淆，导致逻辑混乱。
· 修正：该动作是外展0°纯外旋测试，主要测试冈下肌/小圆肌；Empty Can是肩胛骨平面外展、前臂旋前，测试冈上肌，两者不同。

误解5：试图用“冈上肌后束”统一解释所有矛盾

· 问题：冈上肌后束可解释招财猫后摆极限挤压痛，但不能解释外展0°抗阻外旋痛，因为0°抗阻外旋主要执行者是冈下肌/小圆肌。
· 修正：外旋肌群本身存在肌腱病；冈上肌后束可能参与极度外旋位的挤压痛，但不是唯一主角。

误解6：把招财猫前摆痛归因于肩胛下肌撞击

· 问题：肩胛下肌在肩前方，前摆内旋时若撞击，痛感应在前方，不符合“三角肌深处”痛点。
· 修正：前摆痛是冈下肌/小圆肌肌腱被极限牵拉，不是肩胛下肌撞击。

误解7：把“越过痛弧疼痛减轻”理解为卡压解除

· 问题：如果是卡压，越往后应该越卡越紧，不可能突然不痛。
· 修正：前摆越过痛弧是牵拉终止：到达关节锁定位后肱骨停止运动，肌腱不再被继续拉长，疼痛回落；不是卡压解除。

误解8：卡压点定位在“肩胛冈临近肩峰的下方空隙”

· 问题：肩胛冈根部是空间边界，但不是直接锐利压迫点。
· 修正：直接卡压点是后上关节盂缘；肩胛冈根部是“天花板”，肱骨头把肌腱碾在盂缘“台阶”上。

五、处理方向

1. 精准触诊验证：在招财猫极限外旋疼痛位，于肩峰后外侧角下方深处向后上方触压，寻找能精确重现疼痛的肌腱点。
2. 离心外旋训练：外展0°位抗阻外旋至最大后，缓慢有控制地内旋还原，强化冈下肌/小圆肌肌腱负载能力。
3. 肩胛后缩与肩袖协同训练：如俯卧W字、靠墙W保持，重建肩胛稳定和肩后袖协同。
4. 避免长时间停留在招财猫极限外旋位，减少后上方内部撞击的反复激惹。
5. 排球负荷管理：减少扣球、发球中肩后袖高负荷动作，逐步进阶，不以疼痛为代价。

---

六、一句话总结

这是一例长期排球负荷导致的肩后袖肌腱病：核心是冈下肌/小圆肌肌腱退变，外展90°极度外旋时合并后上方内部撞击（肱骨大结节—后上盂缘），冈上肌后束可能参与挤压痛。外展0°抗阻外旋痛、招财猫前后摆极限痛、背后互抓痛和外展180°末端痛，均可由同一肌腱病在不同长度-张力与挤压窗口下解释；经典肩峰下撞击、单纯三角肌后束急性拉伤和肩胛下肌撞击均不是主诊断。

- DeepSeek 归因于"冈下/小圆肌被拉至最大长度"；
- 但还有三个同样合理的来源：

- **所以"背后互抓痛"不能单独用来定位冈下肌** ⚠️。

2. 考虑 SLAP → 降为次要鉴别 ✅（但不能排除）
3. 三角肌后束拉伤为首选 → 改为深面肌腱病 ✅
4. 把"体前抗阻外旋"当 Empty Can → **修正正确**（Empty Can = Jobe 试验：肩胛平面外展、拇指向下抗阻；0° 抗阻外旋是另一回事）✅
5. 用"冈上肌后束"统一解释一切 → 修正正确（0° 抗阻外旋主要考冈下/小圆）✅
6. 招财猫前摆痛归因肩胛下肌 → 修正正确（位置不符）✅
7. "越过痛弧=卡压解除" → 修正为"牵拉终止" ⚠️（合理但非唯一）
8. 卡压点定位在肩胛冈下方 → 修正为后上盂缘 ✅

### 我再补 4 条
9. **把"内部撞击"当成"已确诊的结构诊断"** → ⚠️ 内部撞击**在临床上很难单独确诊**，多数靠"临床 + MRI（后上盂唇/大结节骨髓水肿/囊肿）+ 关节镜"综合；**无影像时只能算工作假设**。
10. **漏掉"肩胛上神经卡压"** → ⚠️ 后肩痛 + **外旋无力**（冈下肌）是它的典型表现；**肩胛上切迹或冈盂切迹**卡压可完美模仿"冈下肌肌腱病"。**需要 EMG/NCS 才能区分**。
11. **漏掉 GIRD / 后关节囊紧张** → ⚠️ 过顶运动员极常见，可致后肩痛、内旋受限，且与内部撞击互为因果。**应测双侧内旋 ROM 差值**。
12. **把"背后互抓痛"只归因冈下肌** → ⚠️ 也可能是后关节囊、AC 关节、肩胛下肌（见链 5）。

## 七、漏掉的鉴别（建议补进清单）

| 鉴别 | 为什么重要 | 怎么查 |
|---|---|---|
| **肩袖部分/全层撕裂**（冈下） | 与肌腱病处理不同；可有外旋无力 | 外旋抗阻、Lag 征、超声/MRI |
| **肩胛上神经卡压** | 完美模仿冈下肌病；需 EMG | 冈下肌萎缩、EMG/NCS |
| **GIRD/后关节囊紧张** | 过顶运动员常见；与内部撞击互为因果 | 双侧内旋 ROM 差、后囊牵拉试验 |
| **SLAP/后盂唇撕裂** | 可与内部撞击共存（kissing lesion） | MRI/MRA、关节镜 |
| **AC 关节病变** | 背后互抓、横过身体痛 | 交叉内收试验、AC 压痛 |
| **肩胛骨运动障碍（SICK scapula）** | 改变肩袖负荷 | 肩胛观察、动态评估 |
| **颈椎（C5-C6）牵涉** | 后肩痛可来自颈 | 颈椎查体、Spurling |

## 八、如果重来：最优检查顺序

1. **先做规范肩袖查体**：外旋抗阻（0°、90°）、外旋 Lag 征、Drop arm、Jobe、背后 Lift-off；
2. **测双侧内旋 ROM（查 GIRD）** + 后囊紧张度；
3. **查颈椎**（排除牵涉）；
4. **查 AC 关节**（交叉内收、压痛）；
5. **查肩胛运动**（SICK scapula）；
6. **若保守 4-6 周无效，或出现外旋无力/夜间痛 → MRI**（看后上袖、后上盂唇、大结节骨髓水肿、囊肿）；
7. **若怀疑神经 → EMG/NCS**（肩胛上神经）。

## 十、一句话总结

> **这是一例高度合理的"肩后袖肌腱病 + 外展外旋位后上方内部撞击"工作诊断**：**0° 抗阻外旋痛**是最有定位价值的体征，**招财猫极限位痛 + 越过痛弧减轻**支持"长度-张力 + 挤压窗口"的解释，**经典肩峰下撞击、三角肌后束急性拉伤、肩胛下肌撞击**确实都应降级。**但"内部撞击"没有 MRI/关节镜就不能算确诊**，且**肩胛上神经卡压、GIRD、SLAP/后盂唇**这三个"高仿鉴别"必须补进清单。
