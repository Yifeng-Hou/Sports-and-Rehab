## 四、系统三 · 气道与气体交换

**这一组管的是"氧气进不进得来"。**

### 4.1 呼吸困难
**最简单的分级**：

| 情况 | 性质 | 处理 |
|---|---|---|
| 高强度下必然喘，**降强度能缓解** | **正常** | 继续 |
| 胸廓周围酸紧，降强度后缓解 | **呼吸肌疲劳** | 可适当坚持，别硬撑 |
| **与强度不匹配**的极度气短 | 🚩 | 停止、评估 |
| 伴**哮鸣音、咳嗽、胸闷** | 🚩 | 停止、评估（支气管痉挛） |
| 伴**喉部紧缩感、吸气困难** | 🚩 | 停止、评估（声带功能障碍） |

**处置**：降低强度到"能说短句"；**放慢呼吸频率、加深呼气**（不是拼命吸气）；持续不缓解 → 停。

ps：就像你的腿脚一样，你的心肺也是肌肉驱动的，是**肌肉都会累**。提升有氧能力的一个维度，就是通过对**呼吸肌的耐力训练**，提升身体长时间运动的供氧能力。稍微有些喘不过来气是正常的，但如果很难受**千万不要硬撑**。

---

### 4.2 咽痛、嗓子痒、想咳

**感受**：

> 喉咙**发干、发痒**，像有东西在那儿。
> 忍不住想咳一下"清一清"。
> 有时候是轻微的**烧灼感**。

**它多半来自**：**气道表面被"吹干"了。**

**机制**：

安静时你每分钟通气约 6 升，**高强度运动可以到 100 升以上**——**十几倍的干燥气流从口腔冲过去**，把气道表面的水分带走。

黏膜一干，表面液体的**渗透压升高** → 直接刺激**咳嗽感受器** → 想咳。

**处置**：降通气量；**尽量鼻吸口呼**（鼻腔能加温加湿）；少量温水润喉；干燥/寒冷环境戴口罩或围巾。

**预后**：多数停止后自行缓解。**反复出现且伴哮鸣、胸闷、运动后持续咳嗽 → 评估运动诱发支气管痉挛。**

## 五、系统四 · 腹腔：岔气、恶心、腹泻

**为什么把这三个放一起？因为它们共享同一个"底层问题"——运动时腹腔被"断供"了。**

> **一个反直觉的事实**：
> 运动时血液会重新分配——**肌肉和皮肤要血，内脏被"节流"**。
> 高强度时，**内脏血流可以下降 60%–80%**。
>
> 这就是为什么"肚子的事"在运动里特别多：**它不是胃不好，是胃肠道被断电了。**

### 5.1 岔气

**感受**：

> 一侧（多为右侧）上腹或肋缘下，**突然一阵尖锐的痛或绞痛**。
>
> 深吸气、扭转身体时加重；**弯腰、停下来会缓解**。
> 一阵一阵的，来去分明。

**它多半来自**：**膈肌的缺血与痉挛 + 内脏韧带被反复牵拉 + 壁层腹膜刺激。**

> 跑步岔气的主要来源之一是**膈肌——一块骨骼肌**。

**诱因**：训练前 1–2 小时内进食或大量饮水（尤其高渗饮料）；体能水平低；躯干姿势。

**处置**（按顺序试）：

1. **减速**
2. **建立稳定呼吸节奏**（比如三步一吸两步一呼）
3. **加深呼气**、放松腹壁
4. **身体稍前倾、用手按压痛处、弯腰**
5. 通常 1–3 分钟缓解；不缓解就停下来走

**预后**：良性，几乎都能缓解。**反复发作且位置固定、性质改变 → 排除其他腹部问题。**

---

### 5.2 恶心、想吐

**感受**：

> 胃里往上翻。
> 口水突然变多。
> 冒冷汗、脸发白。
> **严重时是一种"全世界都不对劲"的难受**——这很难形容，但每个吐过的人都知道。

**它走的是一条很明确的通路**：

```
                    ┌─ 迷走神经传入（腹腔）─┐
触发因素 ───────────┤                      ├──→ 脑干"呕吐中枢" ──→ 恶心、干呕、流口水、出汗
                    └─ 化学感受器触发区 ←──┘
                       （血液里的物质，没有血脑屏障）
```

**具体触发**：

| 机制 | 说明 |
|---|---|
| **内脏缺血**（最主要） | 胃肠被"断电" → 黏膜屏障受损、代谢产物堆积 → 激活迷走传入 |
| **脱水、高温** | 加重内脏缺血 |
| **前庭**（山地、越野） | 晃动刺激内耳 |
| **过度通气** | 脑血管收缩，加重头晕恶心 |

**处置**：**降强度**（最有效）；补液、降温；训练前 2–3 小时**避免大量进食（尤其高脂高纤）**。

**预后**：降强度后多能缓解。**反复出现且与强度不匹配 → 需评估**（除外心脏、代谢问题）。

---

### 5.3 运动性腹泻

**感受**：

> 腹部**绞痛、翻江倒海**，突然**便意急迫**，有时憋不住。

> 或者强度大时无知觉，稍微慢一些就想上厕所了。

**它其实有两条不同的通路，而且它们的感受和诱因都不一样。**

#### 通路 A · 缺血型（"肚子被断电"）

**典型场景**：持续高强度跑步、天热、比赛。

| 机制 | 说明 |
|---|---|
| **肠道缺血** | 肠屏障受损，内毒素入侵导致应激。且吸收功能下降。 |
| **机械震动** | 跑步时内脏反复颠动（所以跑步比骑车多见） |
| **进食时间不当** | 训练前太近进食 |


#### 通路 B · 受凉型（"汗湿之后腹部一冷"）

**典型场景**：**间歇性运动**——球类、间歇跑、爬山走走停停。**出汗把衣服浸湿，停下来一吹风，腹部凉下去**，十几分钟内就想上厕所。

> **这一型的机制确实和前一种不一样。** 它不是"缺血"，而是**冷刺激引发的反射**——而且叠加了**间歇运动特有**的东西。

**机制分三层，最后叠在一起：**

**① 间歇运动本身：反复的"缺血-再灌注"**

```
持续运动：内脏血流一直低 → 一直缺血
间歇运动：低 → 恢复 → 低 → 恢复 → 低 …
   ↓
每一次"恢复"都是一次再灌注
   ↓
再灌注会产生自由基和炎症介质（缺血-再灌注损伤）
   ↓
肠黏膜屏障的损伤，比持续运动更明显
```

> **这解释了一个很多人观察到的现象**：球类、间歇跑这类**强度有起伏**的运动，比匀速长跑**更容易闹肚子**。
> 原因不是"强度更高"，而是**血流反复重启**。

**② 汗湿 + 蒸发 = 腹部局部快速降温**

- 出汗把衣服浸湿 → **停止运动后蒸发仍在继续带走热量**
- 湿衣服贴在腹部 → **腹部皮肤温度快速下降**
- 皮肤冷感受器被激活 —— 这是第一环

**③ 冷刺激 → 自主神经反射 → 肠道蠕动增加**

```
腹部皮肤温度下降
   ↓
皮肤冷感受器被激活
   ↓
自主神经反射（交感与副交感同时改变）
   ↓
肠道蠕动增加 + 分泌增加
   ↓
便意急迫、腹泻
```

> **一个旁证**：**冷水游泳、大量喝冰水之后急着上厕所**，走的是同一类通路——
> **不是"水不干净"，是冷刺激诱发了排便反射。**


**所以处置要分型**：

| 类型 | 针对性处置 |
|---|---|
| **缺血型** | 调整训练前 2–3 小时的进食（减少**高脂、高纤**、高 FODMAP）；降低强度；充分补水 |
| **受凉型** | **及时换掉湿衣服**（最直接）；**腹部保暖**（干毛巾、护腰）；**间歇时不要站在风口**；避免运动中大量喝冰水 |

**两型共同的处置**：降低强度；充分补水（脱水会加重）。

> **一个成本极低、效果很直接的建议**：
> **间歇训练那天，多带一件干的上衣。**
> 对"受凉型"来说，这一条比任何饮食调整都管用。


> 🚩 **出现以下情况必须就医**：**便血、黑便、发热、持续超过 48 小时、非运动时也发作、体重下降。**
> 这些不是"运动性腹泻"，需要查别的原因。

## 六、系统五 · 体温与免疫

### 6.1 发热、感冒前驱

**感受**：

> 身上**发沉、发酸**（不是训练后的那种酸，是"骨头缝里酸"）。
> **畏寒、起鸡皮疙瘩**。
> 喉咙痛、头昏。
> 一量体温，**37.5 以上**。

**它多半来自**：**免疫系统在打一场仗**，而这场仗**消耗巨大**。

**一条实用的经验规则**（"颈以上"规则）：

| 症状位置 | 处理 |
|---|---|
| **只在颈部以上**（流鼻涕、轻微咽痛、打喷嚏） | 可以**低强度**活动 |
| **在颈部以下**（发热、咳嗽、肌肉酸痛、乏力、腹泻） | **停止训练** |

**处置**：停止训练，休息、补水、观察。退热后**再等 24–48 小时**再恢复，先低强度。

**预后**：普通上呼吸道感染 3–7 天。**退热后仍明显乏力、活动后心悸气短 → 就医（除外心肌炎）。**

## 七、系统六 · 排废：酱油尿

**这是全篇唯一一个"看到就该跑"的症状。**

**感受**：

> 剧烈运动后，肌肉**异常剧痛**——**远远超过平时的酸**。
> **明显无力**，抬手都费劲。
> 肌肉**肿胀、绷紧**。
> 然后——**尿的颜色不对了**：像**浓茶、像可乐、像酱油**。

**它是什么**：**横纹肌溶解**。

```
大量肌纤维被破坏
   ↓
肌红蛋白释放入血
   ↓
经肾脏排泄
   ↓
① 直接毒害肾小管
② 堵塞肾小管（形成管型）
③ 引起肾血管收缩
   ↓
急性肾损伤
```

**诱因**：突然的超大容量训练（**尤其新手**）、高温脱水、热病、他汀类药物、某些感染。

**处置**：🚩 **立即就医，不要等、不要"多喝水看看"。** 补液是关键，可能需要住院监测肾功能。

**预后**：

- **及时处理** → 多数在数周内肾功能恢复
- **延误** → 可致急性肾损伤，少数需要透析

> **和普通酸痛的区分**：
> - **DOMS**：酸、弥散、能活动、**尿色正常**
> - **横纹肌溶解**：**剧痛 + 无力 + 肿胀 + 尿色异常**
>
> **看到尿色不对，就是急诊。这一条不需要任何判断力，只需要你去上厕所时看一眼。**

## 八、速查：全身性症状的红旗

**记不住别的没关系，记住这一张表。**

| 症状 | 红旗 |
|---|---|
| **头痛** | **"雷击样"**（一生最痛）；伴发热+颈硬；伴单侧无力/言语不清 |
| **视物** | **单眼**发黑；视力持续不恢复；视野缺损 |
| **胸闷** | **压榨样、放射到左臂/下颌、伴冷汗** |
| **心悸** | 伴**晕厥**；心率**持续 >150**；家族史 |
| **呼吸** | **与强度不匹配**的极度气短；哮鸣；**吸气困难** |
| **头晕** | 伴晕厥、跌倒；**单侧**症状 |
| **恶心** | 伴胸痛、剧烈头痛；持续呕吐 |
| **腹泻** | **便血、黑便、发热**、持续 >48 小时 |
| **尿** | **酱油色/浓茶色** |
| **肌痛** | **剧痛 + 无力 + 肿胀** |
| **全身** | 发热 + 关节红肿热痛；不明原因体重下降；**夜间静息痛** |
| **运动后** | 晕厥；胸痛不缓解；**无法负重、明显畸形** |

## 结语：全身症状在说"系统"，局部症状在说"零件"

回到开头那个比喻。

> 出现全身不适时，先别急着说"我体质差"或者"今天状态不好"。
> 先问自己：**是供血的问题？供能的问题？气道的问题？指挥的问题？腹腔的问题？还是排废的问题？**

**因为在六个系统里，有一个的报警是绝对不能拖的**——那就是**尿的颜色**。

**其余五个，大多可以"降强度、观察、调整"。**

**而这一个，只能"立刻去"。**
