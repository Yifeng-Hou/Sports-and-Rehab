# 零件在说话（三）：撕 · 裂

### 运动不适 · 第三篇（三）——组织正在被拉坏

> **接上一节。**
>
> 上一节的四个信号（烧、空、抽、麻）都发生在**"用得太狠"或"用得太久"**的时候——组织的结构还是完整的，只是"运转不过来"。
>
> 这一节不一样。这一节讲的是"**撕**"——**受力超过了结构的承受极限**。
>
> 这是一个质变：从"累了"到"坏了"。

---

## 本节架构

```
  一 · 先分清："撕"有三种来源
        ├ 真的撕了（拉伤）
        ├ 只是被拉扯得敏感（DOMS / 筋膜受刺激）
        └ 是神经在"过电"（神经源性）
              │
              ▼
  二 · 肌肉撕裂状疼痛
        ★ 用三个问题分清
              │
              ▼
  三 · 足底撕裂状疼痛
        ★ 足弓是"弓"，足底筋膜是"弦"
              │
              ▼
  四 · 各种剧痛
        ★ 拉伤 I / II / III 级，感受和预后对应
```

**一句话导读**：

> **"撕"字的重点不在"有多痛"，而在"什么时候开始的"。**
> **当时就撕 vs 第二天才敏感**——这是本节最重要的分界线。

---

## 一、先分清："撕"有三种完全不同的来源

你说"这里像被撕开了"的时候，可能是三件不同的事：

| 来源 | 本质 | 关键特征 |
|---|---|---|
| **① 真的撕了（肌肉拉伤）** | 肌纤维或肌腱的纤维**真的断了**（哪怕只是微观的） | **受伤那一瞬间就有感觉** |
| **② 只是被拉扯得敏感** | 结构完整，但**处于微损伤/炎症状态**（如 DOMS 期间） | **延迟出现**，伴随广泛酸痛 |
| **③ 神经在"过电"** | 神经被牵拉或压迫 | **沿一条线走**，伴麻木或针刺 |

**这三者的处理完全不同**：

- ① 要**保护**（停止、制动）
- ② 要**轻度活动**（反而恢复更快）
- ③ 要**改姿势、松压迫**

> **所以"撕"这个字不能直接用来判断严重程度。** 得往下问。

---

## 二、肌肉撕裂状疼痛

**感受**：

> **"辣辣的"**——不是钝钝的酸，也不是尖锐的刺。
>
> 像有一小块地方**被什么东西扯住了**，**只有拉到某个位置才痛**。
> 一退出那个姿势，就缓解。
> 有时会觉得"这块地方不太敢用力"。

**它出现在**：拉伸时腿还没到平时的高度就"顶住了"；走路时后腿蹬地那一下；某个转体动作。

### 三种可能，怎么分

| 可能 | 特点 | 病程 |
|---|---|---|
| **轻度肌肉拉伤（I 级）** | **即刻**出现，局限一点，**抗阻收缩时会痛** | 1–2 周 |
| **筋膜/肌腱交界处受刺激** | 牵拉触发，位置在**肌肉的某一端**（靠近关节那头） | 数天至数周 |
| **延迟性酸痛期间的"牵拉敏感"** | 伴随**广泛酸痛**，1–3 天后出现，和 DOMS 同步 | 与 DOMS 一起消退 |
| **神经源性烧灼痛** | **沿一条线走**，伴麻木或针刺 | 需评估 |

### 用三个问题分清（这一节最实用的部分）

> **① 是不是受伤那一瞬间就有感觉？**
> - **是** → 更像**拉伤**（真的撕了）
> - **不是**（第二天才出现） → 更像 **DOMS 的牵拉敏感**
>
> **② 有没有淤青、肿胀、明显无力？**
> - **有** → **更严重**，按拉伤处理，考虑就医
> - 没有 → 相对轻
>
> **③ 抗阻收缩痛不痛？**（让这块肌肉主动用力，比如屈膝对抗阻力）
> - **痛** → 更像**肌肉/肌腱**的事
> - **不痛，只是牵拉痛** → 更像**筋膜**的事

> ⚠️ **这里要诚实一点**：单凭感觉**确实不能定性**。你不需要自己下诊断——你只需要判断**"该不该停"**。而上头三个问题足够回答这个。

### 处置

**当场**：

1. **停止诱发动作**
2. **不要"拉开试试"**——急性期反复牵拉会加重
3. 如果只是轻微牵扯感、不影响功能 → 可以继续低强度活动，但避开那个方向

**前 48–72 小时**：

- **相对休息**（不是完全不动，做不痛范围内的活动）
- 加压、抬高（如果肿）
- 冰敷**只在明显疼痛时短期用**（每次 10–15 分钟；证据有限，不要长时间冰）
- **避免**：热敷、酒精、深度按摩、强行拉伸

**长期**：

- **渐进负荷**恢复（这是关键，急不得）
- **离心训练**——对肌肉和肌腱的恢复，这是证据最好的手段
- 找出诱因：**是不是某个动作模式让这块肌肉反复超负荷，是不是下次一动该怎么疼还是怎么疼**

> 🚩 **就医信号**：
> **明显淤青、无法发力、能摸到"凹陷"、疼痛持续超过 2 周无改善。**

## 三、足底撕裂状疼痛

**感受**：

> 足底**像被撕开**、或者**烧灼、刀割**一样。
>
> 多在**足弓**或**足跟内侧**。
> **落地时明显**；走一会儿活动开了，可能反而减轻。

### 先认识一个结构：足弓是"弓"，足底筋膜是"弦"

```
     ┌──────────────────────┐
     │   足弓（骨与关节排列）│   ← 弓
     └───────────┬──────────┘
                 │
        ═════════╧═════════
        足底筋膜（厚韧带）      ← 弦
        从跟骨一直连到脚趾
```

**关键**：这个"弓"是靠"弦"来维持的。

> **弓塌了（扁平足）→ 弦被拉长 → 张力急剧升高 → 更容易出问题。**

### 一处命名要澄清

慢性"**足底筋膜炎**"这个名字**不太准**。

- 组织学上它主要是**退变**——纤维增厚、胶原排列紊乱
- **不是单纯的"发炎"**

但它和肌腱病有一处不同：**足底筋膜的神经末梢更密集**，而且急性期炎症成分更明显——**所以它疼得特别厉害**。

更准确的叫法是"**足底筋膜病**"或"**足跟痛**"。

### 根本原因：分三层看

大部分人只知道第一层。真正难治的，往往是第二层。

| 层次 | 因素 | 说明 |
|---|---|---|
| **一 · 负荷本身** | 站立/行走总量突增（**最常见**）、体重增加、长时间站立职业、跑量/跑面/鞋的改变 | 直接的"超负荷"来源 |
| **二 · 力学放大** | **小腿紧张 / 踝背屈受限** | 小腿三头肌—跟腱—足底筋膜是**一条连续的张力线**，小腿紧 → 足底负荷↑ |
| | **足弓塌陷（扁平足）** | **弓塌了，弦被拉长，张力急剧升高** |
| | **高足弓** | 缓冲差，冲击直接传到足底 |
| | **足内在肌无力** | 内在肌是足弓的**主动**支撑，弱了 → 筋膜被动代偿 |
| | 臀肌/核心控制不足 | 影响步态中的冲击吸收 |
| **三 · 组织本身** | 年龄（40–60 高发）、**肥胖（BMI 是独立危险因素）**、糖尿病/血脂异常 | 修复能力下降 |

> **为什么"弓塌了"这件事值得单独查**：因为如果根本原因在足型，**光靠休息和拉伸会反复发作**，加上足弓支撑才能断根。

**审稿人补充（大喊）：足弓辣辣的快去看一下足型吧！有问题尽快用支撑鞋垫。实测好用，很长时间没有足底痛了。**

### 处置

| 手段 | 证据 | 说明 |
|---|---|---|
| **负荷管理**（减少站立/行走总量） | 基础 | 不管理负荷，其他都是白搭 |
| **（对于筋膜炎）**小腿 + 足底拉伸 | 好 | **对"晨起第一步痛"特别有效** |
| **足内在肌强化**（短足练习、脚趾抓毛巾） | 增长中，推荐 | 让足弓重新有"主动支撑" |
| **足弓支撑鞋垫** | 中等 | **对扁平足效果更明显** |

夜间支具、体外冲击波、激素注射参考**医嘱**

### 预后

- **多数良好，但很慢**：典型 **6–12 个月**
- 保守治疗约 **80%–90%** 明显改善
- **复发常见**，尤其在负荷回升时
- 关键不是"打一针就好"，而是**把负荷和力学因素一起处理**

### 需要鉴别的三种情况

| 情况 | 特点 |
|---|---|
| **典型足底筋膜病** | 足跟内侧，**早晨起床第一步最痛** |
| **跖间神经瘤** | 疼痛在**足底前部**，伴**麻木或"像踩到石子"** |
| 🚩 **应力性骨折** | **足背或足底某个固定一点**，**夜间痛 + 冲击痛** → 需影像 |

## 四、各种剧痛（拉伤）

**感受**：

> **受伤那一瞬间**的一道锐痛，或者明确的"**撕裂感**"。
>
> 有时会听到或感觉到"**啪**"的一下。
> 之后：**收缩无力**、局部**压痛很明显**、可能很快肿起来。

> **注意和上一节"肌肉撕裂状疼痛"的区别**：
> 那一节多数是"牵拉时才痛、平时还好"；**这一节是"当时就痛、之后一直痛"**。

### 分三级：感受、功能、预后对应

| 分级 | 损伤程度 | 感受 | 功能 | 预后 |
|:---:|---|---|---|---|
| **I 级**（轻度） | 少量纤维损伤 | 痛，但**能抗阻收缩**；**无明显淤青** | 基本能走能动能练（但要避开） | **1–2 周** |
| **II 级**（中度） | 部分撕裂 | **明显疼痛**；力量**下降**；可能有**淤青、肿胀** | 走路可能跛，某些动作做不了 | **3–6 周** |
| **III 级**（重度） | 完全撕裂 | **无法收缩**；**能摸到"凹陷"**；**明显淤肿** | 基本不能负重 | **数月至手术** |

> **一个现场可做的判断**：**能不能抗阻收缩？**
> 能 → 多半是 I 级；明显力弱 → II 级；完全使不上劲、能摸到坑 → III 级，**直接去急诊**。

### 当场处置

**立即停止。不要"试着动一动看看"。**

1. **保护**——避免进一步牵拉
2. **适度加压**（弹力绷带）
3. **抬高**
4. **前 24–48 小时避免**：热敷、酒精、深度按摩（都会增加出血和肿胀）

> ⚠️ **关于冰敷**：证据其实有争议。**有明显疼痛时可以短时间用**，但**不要长时间、反复冰**——过度冰敷可能延缓恢复。

### 就医信号

- **无法负重**
- **能摸到凹陷**
- **大面积淤青**
- 疼痛**持续加重**而不是减轻

### 长期：恢复期的两个关键

1. **离心训练**——肌肉拉伤康复中**证据最好**的手段
2. **渐进负荷**——**过早回到原强度是再伤的主要原因**

> **一个规律**：肌肉拉伤的"再伤率"不低，而**再伤往往比第一次更严重**。所以宁可多等一周，不要早回三天。

## 本节小结

| 感受 | 先问 | 结论 |
|---|---|---|
| **牵拉才痛，平时还好** | 当时就痛？还是第二天？ | 当时 → 拉伤；第二天 → DOMS 敏感 |
| **足底像撕开、晨起第一步最痛** | 有没有扁平足？小腿紧不紧？ | 足底筋膜病，查力学因素 |
| **当时"啪"一下、之后无力** | 能不能抗阻收缩？ | 分级 I/II/III，决定等多久 |

> **这一节的核心**：
> **"撕"的严重程度，不是由"多痛"决定的，而是由"当时就痛还是延迟痛""能不能用力""有没有凹陷和淤青"决定的。**
