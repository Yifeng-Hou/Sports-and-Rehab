## 一、先给你一个分诊框架：三问

全身性症状来的时候，**先别慌，先问三个问题**：

| # | 问题 | 判断 |
|:---:|---|---|
| **1** | **是红旗吗？**（见文末速查） | 是 → **停止 + 就医，不用往下问了** |
| **2** | **和强度匹配吗？** | **匹配** → 多半是正常代价；**不匹配** → 有问题 |
| **3** | **换个条件能缓解吗？**（降强度、坐下、补水、降温） | **能** → 可以调整继续；**不能** → 停 |

> **注意第 2 问的分量。** "喘"是正常的，"跑得比谁都慢还喘得说不出话"就不正常。**症状本身不是问题，"症状与付出的不匹配"才是问题。**

## 二、系统一 · 供血与供能

**这一组管的是"有没有足够的血和糖送到大脑"。**

它们的感觉都指向同一件事：**大脑短暂"缺料"**。

### 2.1 眼前发黑

**感受**：

> 视野**从边缘开始收缩**。
>
> 像有人慢慢把一个光圈关小——先是周围变暗、变窄，最后只剩中间一个小亮点，或者干脆整片变成灰白色。
>
> 全程可能只有两三秒。恢复的时候是反过来的：光从四周回来。

**它多半来自**：**全脑灌注压短暂下降**——也就是"血一时供不上"。

**什么时候会遇到**：突然站起（体位性低血压）；憋气用力后松劲（瓦尔萨瓦动作）；脱水；低血糖；长时间站立不动。

**处置**：**立刻坐下或蹲下，最好是躺平并抬高双腿。** 不要试图"站一会儿就好了"——那是最容易摔倒的姿势。

> 🚩 **一个必须分清的细节**：
> **双眼同时发黑、从周边开始** → 多为**全脑灌注不足**，相对良性。
> **只有一只眼发黑**（像拉窗帘一样）→ 可能是**颈动脉系统的短暂缺血**，这是**卒中的前兆**，必须马上就医。

---

### 2.2 头晕：一个词，四种完全不同的东西

**中文的"头晕"是个筐，什么都往里装。** 但在医学上，它至少分四种——**而且处理方式截然不同**：

| 类型 | 感受 | 来源 |
|---|---|---|
| **眩晕**（vertigo） | **天旋地转**。感觉是"我在转"或"房间在转"，常伴恶心、不敢睁眼 | **前庭系统**（内耳） |
| **晕厥前**（presyncope） | **发飘、要晕过去、眼前发黑**、耳朵发闷 | **全脑灌注不足** |
| **平衡障碍**（disequilibrium） | **走路不稳、站不住**，但**不转也不飘**。实测：这就是**喝大了**以后的感觉，空间感不受影响，但是走路会画大龙。 | **小脑 / 本体感觉** |
| **头昏**（lightheadedness） | **头重脚轻、发木、像隔一层雾** | **代谢 / 自主神经 / 心理** |

在运动场景里，最常见的是后两种：**晕厥前（供血）和头昏（代谢/疲劳）。**

**常见诱因：每一种属于哪一型、为什么、怎么办**

> **"头晕"这个词本身不含信息。** 所以下面每一种，我都会**明确标出它落在上面四型中的哪一型**——因为**落到哪一型，才决定该查什么、该怎么做**。

#### ① 体位性低血压 → **晕厥前**

**感受**：**站起来那一下**，眼前发灰、发飘、腿软，有时耳朵发闷。**几秒到几十秒自己缓解。**

**原理**：

- 站立时，重力让大约 **500–800 mL 血**滞留在下肢和内脏
- 正常情况下，人体几秒内响应：**缩血管 + 心率升高**
- 但脱水、疲劳、高温、久站之后，**这套反射响应变慢或幅度不够** → 脑灌注压短暂下降 → 眼前发灰

**为什么"几秒就好"**：因为代偿**终于起作用了**。这个"几秒"正是压力反射的反应时间。

**处置（这一型专属）**：

1. **立刻坐下或蹲下**——不要站着等它过去，这是最容易摔的姿势
2. **绷紧腿部肌肉**（交叉腿、绷大腿、握拳）——肌肉泵把血挤回心脏，这是这一型**最快见效**的方法
3. **分步起身**：卧 → 坐 30 秒 → 站 30 秒 → 走
4. 长期：训练前补足水分；避免久站不动；训练结束做整理活动

#### ② 脱水 → **晕厥前 + 头昏**（混合）

**感受**：**站起时发飘**（晕厥前那一半）+ **头发木、注意力差**（头昏那一半）。伴**口渴、尿色深、心率偏快**。

**原理**：

- 出汗丢的是**低渗液**（水多于盐）→ **血浆容量下降、血液变浓**
- 血量少 → 每搏量少 → 为维持心输出量，**心率必须升高**（"心血管漂移"）
- 血量少 → 对体位变化更敏感 → **站起来更容易发飘**
- 同时脑灌注的"余量"变小 → 出现头昏那一半

**处置（这一型专属）**：

1. **补含电解质的液体**，小口多次——不要一次猛灌（加重胃部不适，也不利于吸收）
2. 坐下休息，**不要继续训练**
3. **判断依据看尿色**：淡黄 = 还行；深黄/琥珀 = 明显缺水
4. 长期：训练前虽然不要猛灌，但是要喝水。训练过程中也要补水。

#### ③ 低血糖 → **头昏 + 交感兴奋症状**

**感受**：**头昏、注意力涣散、脑子转不动**，同时**手抖、心慌、出冷汗、强烈饥饿感**。严重时意识模糊、说话不清。

**原理**：这一型和"供血"无关，是**"缺糖"**。

- 大脑主要靠葡萄糖供能
- 血糖下降 → 下丘脑感知 → **激活交感**（释放肾上腺素）→ 这就是手抖、心慌、出汗的来源
- 同时脑细胞能量不足 → 注意力、判断力、协调性下降 → 这就是"头昏、发木"的来源

> **一个极快的鉴别**：低血糖的"手抖心慌"和心悸那一节的"跳得重"不一样——**低血糖一定伴出汗和饥饿感，而且补糖后几分钟内明显改善**。这是最快的鉴别方法。

**处置（这一型专属）**：

1. **立即补 15–20 g 快速吸收的糖**（含糖饮料、葡萄糖片、糖果）
2. **坐下**，等 10–15 分钟
3. 缓解后**再补一点复合碳水**（面包、饼干），防止再次下滑
4. **本次训练终止**
5. 长期：训练前 2 小时进食；**不要空腹做中高强度**

#### ④ 睡眠不足 / 中枢疲劳 → **头昏**

**感受**：**头重脚轻、发木、像隔一层雾**。**不转、不发飘、也不影响走路**。伴注意力涣散、不想动、反应变慢。

**原理**：

- 睡眠剥夺 → 腺苷在脑内堆积 → **皮质兴奋性下降、警觉网络效率下降** → 主观体验就是"发木"

**处置（这一型专属）**：

1. **不要硬上强度**。这一型最不该"靠意志克服"——**注意力下降本身就会让动作变形、受伤风险上升**
2. 补水、少量碳水、通风降温，观察 10–15 分钟
3. **不缓解 → 放弃本次训练。回去睡觉比练这一节有价值得多**
4. 长期：规律睡眠；**避免连续熬夜后训练**

#### ⑤ 感染前驱 → **头昏**

**感受**：**头发沉、身上发酸**（不是训练后那种酸，是"骨头缝里酸"）、**畏寒、起鸡皮疙瘩**。伴咽痛、轻度发热。

**原理**：免疫系统启动 → 释放炎症因子作用于中枢 → 产生所谓"**生病行为**"：嗜睡、食欲下降、注意力差、情绪低。**这是身体在强制你休息。**

**处置（这一型专属）**：

1. **停止训练**——这一型没有"低强度也行"的空间（见**下篇**《发热》一节的"颈以上"规则）
2. 休息、补水、观察体温
3. 退热后**再等 24–48 小时**再恢复

#### ⑥ 贫血 → **头昏 + 运动后心率偏高**

**感受**：**长期易疲劳、头昏**；**同样配速下心率明显比别人高**；运动后恢复慢。

**原理**：血红蛋白少 → **携氧能力下降** → 同样的运动强度需要更高心输出量补偿 → **心率偏高**；脑和肌肉的氧供都处在"边缘"。

**处置（这一型专属）**：

1. **就医查血常规**——这是需要检查的一型，不是"调整一下就好"
2. 查清之前**降低训练强度**
3. ⚠️ 女性 + 月经量大 + 素食者，风险更高

---

**一张对照表，方便快速定位**：

| 诱因 | 属于哪一型 | 关键鉴别词 | 首要处置 |
|---|---|---|---|
| **体位性低血压** | **晕厥前** | "站起来那一下"、几秒缓解 | 坐下 + 绷腿 |
| **脱水** | **晕厥前 + 头昏** | 口渴、尿深、心率快 | 补电解质液 |
| **低血糖** | **头昏 + 交感症状** | **手抖、出汗、饥饿**、补糖即好 | 补 15–20 g 糖 |
| **睡眠不足** | **头昏** | 发木、不转不飘、注意力差 | **别练，去睡** |
| **感染前驱** | **头昏** | 畏寒、肌肉酸痛、咽痛 | 停训 |
| **贫血** | **头昏 + 心率高** | 长期疲劳、同强度心率高 | **查血常规** |

> ⚠️ **不要习惯性把"头晕"归因为"累了"。**
> 它是**非特异性症状**——同一个词背后可能是血压、血糖、血量、感染、贫血中的任何一个。
> **但只要你问对两个问题，就能大致定位：**
> **① 是不是"站起来那一下"？（是 → 体位性）**
> **② 有没有手抖、出汗、饥饿？（有 → 低血糖）**

### 2.3 困顿

**感受**：

> 眼皮沉，像挂了东西。
> 注意力**像隔了一层雾**——别人说话你要"过一道"才反应过来。
> 四肢发懒，不是酸，是**"不想动"**。

**它多半来自**：**中枢神经系统的"功率不足"**。可能是睡眠债、血糖低、轻度脱水、感染前驱，或者累积疲劳。交感神经紧张，导致**心率偏快、心率变异性下降**。

**处置**：

- **不要硬上强度。** 困顿状态下训练，受伤风险和动作变形风险都上升，而且练不出效果
- 补水分、补少量碳水、通风降温
- 10–15 分钟不缓解 → **放弃本次训练，回去睡觉**

> **一个很实用的态度**：**"今天不练"是一种训练决策，不是失败。** 一次跳过不会让你退步，一次硬撑可能让你停两周。

### 2.4 运动后头晕：和"运动前头晕"不是一回事

**感受**：

> 训练结束，刚停下来，**几分钟内开始发飘、眼前发灰、想躺下**。
> 有时候伴恶心、出冷汗。

**它多半来自**：**运动后低血压**。

**机制很清楚**：

```
运动时：骨骼肌血管大幅扩张（要散热、要供氧）
        ↓
肌肉收缩本身在"挤血回心"（肌肉泵）
        ↓
突然停下 → 肌肉泵停了
        ↓
扩张的血管里滞留大量血液（尤其在下肢）
        ↓
回心血量 ↓ → 心输出量 ↓ → 血压短暂下降
        ↓
脑灌注 ↓ → 头晕、眼前发灰
```

**处置**：**不要立刻静止。** 做 5–10 分钟的**低强度整理活动**（慢走、慢骑），让肌肉泵继续工作，让血管慢慢回收。

**预后**：**良性**，几乎都能通过"不骤停"预防。反复出现且程度重 → 查一下血压和心脏。

## 本篇小结 · 下一篇讲什么

- **眼前发黑**：全脑灌注短暂下降 → **从周边开始"关光圈"**（周边视网膜对缺血更敏感）
- **头晕**：一个词四种东西 → **站起发飘**想血压血糖、**发木**想睡眠想脱水、**天旋地转**看前庭、**走路不稳**想小脑
- **困顿**：不是"脑供血不足"，是**脑的处理速度变慢了**
- **运动后头晕**：肌肉泵停了，血滞在下肢
