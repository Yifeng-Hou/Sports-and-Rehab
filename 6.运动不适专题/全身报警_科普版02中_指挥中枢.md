# 全身报警（中）：指挥中枢

### 运动不适 · 第二篇（中）——节律乱了的时候

> **接上篇。**
>
> 上篇讲的是"**大脑缺料**"——血、糖供不上（眼前发黑、头晕、困顿、运动后低血压）。
> 这一篇讲的是"**节律乱了**"——同一个大脑，但问题不在"料"，在**调控**。
>
> 它们的共同点是：**你感觉到的不是"累"，而是"乱了"**——心跳不对、胸口发闷、脑袋作痛、睡不着。

---

## 本篇架构

```
  （接上篇：分诊三问 + 系统一 · 供血与供能）
                │
                ▼
  三 · 系统二 · 指挥中枢
                │
   3.1 心悸 ──────── 跳得重 / 跳得乱 / 漏一拍
                │
   3.2 胸闷 ──────── 四种来源，处置方向相反
        ├ 心脏（牵涉痛）  → 立刻停、求救
        ├ 过度通气        → 减慢呼气
        ├ 胃食管反流      → 改吃饭时间
        └ 呼吸肌疲劳      → 降强度
                │
   3.3 头疼 ──────── 四种机制，四种"谁在痛"
        ├ 运动性 → 血管壁

```

**读法建议**：

- **3.2 胸闷**和 **3.3 头疼**都按"四种诊断"展开，每种都有独立的机制和处置——**不要只读开头那张表**。
- **3.2 里"心脏"那一型是全篇唯一的"零商量"红线**，其余都可以调整后继续。

## 三、系统二 · 指挥中枢

**这一组是"自主神经 + 大脑"的报警。** 它们的特点是：**你感觉到的不是"累"，而是"节律乱了"。**

### 3.1 心悸

**感受**：这个感觉有**三种不同的味道**，意义也不同：

| 感觉 | 描述 | 更可能是 |
|---|---|---|
| **"跳得重"** | 每一下都**砸在胸口**，能感觉到撞击；心率可能不快 | 交感兴奋、每搏量增加 |
| **"跳得乱"** | 忽快忽慢、没有规律 | 心律失常 |
| **"漏一拍"** | 突然"卡"一下，然后"咚"地补一下 | 早搏 |

心悸**常常没有**心律失常 | 心律失常**不一定**被感觉到 |

**"跳得重"的生理本质**：心跳的"重"来自**机械冲击**，取决于**每搏输出量**和**心肌收缩力**。交感兴奋时两者都上升 → 每次搏动的冲击变大 → 胸壁的机械感受器被激活 → 你"感觉到"心跳。

> **所以"跳得重"的本质，是一次搏动更有力，而不是"节律乱了"。**

**为什么"有诱因 + 能自行缓解"指向良性**：

- **咖啡因**：阻断腺苷受体 → 交感张力升高
- **紧张**：交感激活 + **内注意增强**（你开始关注心跳，于是"感觉到"了本来感觉不到的）
- **睡眠不足**：交感张力高

而**"坐一会儿就好"是很关键的证据**——**持续的、病理性的快速心律失常不会因为坐下而终止**（室上速、室速需要药物、迷走刺激或电复律）。能坐好的，多半是**一过性的自主神经状态**。

**处置**：坐下、缓慢深呼吸、避免咖啡因；**不要大口喘气**（会加重）。

> 🚩 **要评估的信号**：伴晕厥或近乎晕厥、伴胸痛、心率**持续 >150** 或不规则、**家族史**（年轻猝死/遗传性心律失常/心肌病）、已知结构性心脏病、发作越来越频繁越来越长。

### 3.2 胸闷

**感受**：

> 胸口**像被压住、被箍住，或者压了一块石头**。
>
> 有时候是"吸不满"，有时候是"闷得发慌"。

**要分清四种完全不同的胸闷**：

| 类型 | 感受 | 提示 |
|---|---|---|
| **"压榨感"** | 被压、被箍、紧缩，**可能放射到左臂/下颌/背部** | 🚩 **心脏** |
| **"吸不满"** | 吸气到一半就"上不去"，常伴叹气、手脚发麻 | **过度通气 / 焦虑** |
| **"堵 / 烧"** | 胸骨后堵、烧灼、酸水上涌 | **胃食管反流** |
| **"酸紧"** | 胸廓周围酸胀发紧，降强度能缓解 | **呼吸肌疲劳** |

> **这四种的处置方向完全不同**，所以下面分开讲。

#### ① 心脏来源：牵涉痛的机制

**感受**：**胸骨后压榨、紧缩、像压了块石头**。可能**放射到左臂内侧、下颌、后背、上腹**。常伴**冷汗、恶心、气短、濒死感**。

**原理（为什么"放射"）**：

```
心肌缺血
   ↓
缺血代谢产物（腺苷、乳酸、缓激肽）堆积
   ↓
刺激心脏的交感传入纤维
   ↓
信号经上胸段脊髓（T1–T5）上传
   ↓
★ 关键：内脏传入 和 体表传入 在脊髓同一节段"会聚"
   ↓
大脑分不清信号来自心脏还是来自左臂/下颌
   ↓
"误判"为左臂、下颌痛  ← 这叫牵涉痛
```

> **所以"放射痛"不是痛"跑过去了"，而是脊髓层面的定位错误。** 这也是为什么心脏问题可以表现为牙痛、肩膀痛、上腹痛——**这正是它危险的地方。**

**处置（这一型专属）**：

1. **立即停止运动，坐下或半卧位**
2. **立即呼救 / 拨打急救电话**——不要自己开车去医院
3. **不要"再试试能不能缓解"**，不要自行服药（除非已有医生开的硝酸甘油）
4. 有条件可嚼服阿司匹林（**仅在急救指导下方可**）

> 🚩 **红线**：**压榨样 + 放射 + 冷汗 + 恶心 = 立刻停、立刻求救。这一条没有任何商量余地。**

#### ② 过度通气 / 焦虑

**感受**：**"吸不满"，需要频繁叹气或打哈欠**。同时**手脚发麻、口周发麻**，可能手指抽搐。伴**头晕、心慌**。**越注意越难受。**

**原理（一个恶性循环）**：

```
焦虑 / 紧张
   ↓
呼吸变快变深（自己可能没意识到）
   ↓
CO₂ 排出过多 → 低碳酸血症
   ├─→ 脑血管收缩 → 脑血流下降 → 头晕
   └─→ 血液 pH 升高（呼吸性碱中毒）→ 游离钙下降
          ↓
       神经肌肉兴奋性升高 → 手脚麻木、口周麻、肌肉抽动
   ↓
"我是不是吸不上气？" → 更用力呼吸
   ↓
CO₂ 更低 → 更难受  ← 循环闭合
```

**处置（这一型专属）**：

1. **关键是"减慢呼气"，不是"深吸气"**——很多人拼命深吸，反而让 CO₂ 降得更低，越吸越晕
2. **延长呼气**：吸 4 秒、呼 6–8 秒；或者用"吹蜡烛"式的缩唇呼气
3. 坐下、放松肩颈、转移注意力（聊点别的比"专注呼吸"更有效）
4. **反复发作 → 评估焦虑**，因为这一型背后往往是心理因素，不是肺的问题

#### ③ 胃食管反流

**感受**：**胸骨后"堵"或"烧"**，有时**酸水上涌**。**饭后加重、躺下加重、弯腰加重**。

**原理**：

- 运动、进食、咖啡、高脂食物会让**食管下括约肌张力下降**
- 胃内容物反流 → 盐酸刺激食管黏膜 → 烧灼、堵
- ★ **关键机制**：**食管的感觉传入和心脏的传入在脊髓层面有会聚** → 所以食管问题可以"伪装"成心脏病

> **这正是为什么"胸闷"必须先排除心脏，才能归因于胃。** 不是因为医生保守，是因为**这两件事的感觉通路有重叠**。

**处置（这一型专属）**：

1. **训练前 2–3 小时避免大量进食**，尤其高脂、咖啡、辛辣、碳酸饮料
2. 抬高床头（睡觉时）
3. 抗酸药可短期缓解（**按药师/医生指导**）
4. **反复发作 → 评估**（长期反流可导致食管炎）

#### ④ 呼吸肌疲劳

**感受**：**胸廓周围酸胀、发紧**，"吸不深"。**降强度能缓解**。

**原理**：膈肌和肋间肌承担长时间高强度通气，反复收缩后**收缩力下降**（膈肌是会疲劳的，可用膈神经刺激测出）。此时大脑要"更用力地指挥呼吸"，主观上就是"胸廓酸紧"。

**处置（这一型专属）**：

1. **降低强度到"能说短句"**
2. **放慢呼吸频率、加深呼气**（不是拼命吸气）
3. 改善有氧能力（耐力上去了，同样配速的通气需求更低）
4. 持续不缓解 → 按**下篇**《呼吸困难》一节的分级排查

### 3.3 头疼

**先记住一件事**：**大脑本身没有痛觉。** 头痛的"痛"来自**脑膜、血管、颅神经、颅周肌肉**——记住这一点，下面的四种机制就都好理解了。

| 类型 | 感受 | 场景 |
|---|---|---|
| **运动性头痛** | **搏动性、双侧**，像脑袋跟着心跳涨；强度越大越明显 | 长跑、高强度耐力 |
| **用力性头痛** | **爆发性的、几秒钟的**，像被"敲了一下" | 大重量、憋气用力的瞬间 |
| **体位性头痛** | **站起来加重、躺下减轻** | 脱水、脑脊液压力问题 |
| **紧张性头痛** | **像被带子箍住**，双侧、压迫感 | 焦虑、疲劳、姿势 |

#### ① 运动性头痛：血管被"撑"开了

**感受**：**跟着心跳一下一下地涨**，双侧（常常整个头或后脑），强度越大越明显。停下来后几分钟到几小时缓解。

**原理**：

```
大肌群持续运动
   ↓
收缩压显著升高（可以到 160–200 mmHg）
   ↓
脑循环本来有"自动调节"——血压变，脑血流不变
   ↓
但血压超出调节范围 → 调节失灵 → 脑血管被动扩张
   ↓
血管壁被撑开 → 牵张血管周围的三叉神经末梢
   ↓
搏动性头痛（"跟着心跳"就是因为血管在随脉搏扩张）
```

**为什么是"搏动性"**：因为血管**随每一次心跳扩张一次**，所以痛也跟着跳一下。**"搏动"这个特征本身就是"血管参与"的证据。**

**加重因素**：高温、脱水、低血糖、睡眠不足、突然上强度。

**处置（这一型专属）**：

1. **充分热身**——让血压渐进升高，比突然冲上去好得多
2. **降强度**，把心率压回舒适区间
3. **补水、降温**
4. 反复发作 → 需医生评估（有预防性用药，但需处方）
5. ⚠️ 不要在**高温 + 脱水 + 空腹**三个条件同时存在时练高强度

#### ② 用力性头痛：颅内压被"挤"上去了

**感受**：**几秒钟，爆发性**。像被敲了一下，或者"脑子里炸开"。**多发生在憋气用力的那一个瞬间。**

**原理**：

```
闭气用力（瓦尔萨瓦动作）
   ↓
胸腔内压骤升（可达 100+ mmHg）
   ↓
静脉回流受阻
   ↓
颅内静脉压骤升 → 颅内压瞬间升高
   ↓
牵张脑膜和血管（这些结构有痛觉）
   ↓
爆发性头痛
   ↓
呼吸恢复 → 压力回落 → 几秒内缓解
```

**处置（这一型专属）**：

1. **不要闭气到底**——正确的做法是**用力时呼气**，或者至少不要"闭死"
2. 多数是良性的，**随呼吸调整会消失**
3. 🚩 **但"第一次出现"必须认真对待**——因为**动脉瘤破裂也发生在用力瞬间，表现可以非常像**（见下方红旗）
4. 反复出现 → 需评估

> **这就是为什么"憋气"这件事需要专门讲。** 它不只是让人头晕（见系列另一篇），还能在颅内制造一次压力冲击。

#### ③ 体位性头痛：脑"沉下去"了

**感受**：**站起来加重、躺下减轻**。可以是闷的，也可以是胀的。有时伴耳鸣、视物模糊。

**原理**：

- 正常情况下，**脑脊液像一个"水垫"**，把脑托在颅腔里，缓冲重力和冲击
- 直立时颅内静脉压下降；**如果脑脊液容量不足（低颅压）**，脑就会**往下沉**
- 下沉的脑**牵拉脑膜、血管、颅神经**（这些都有痛觉）→ 头痛
- **躺下时重力消失** → 牵拉减小 → 缓解

> **"站起来重、躺下轻"这个特征，本身就几乎可以确定是"压力/容量"问题**，而不是"肌肉"或"血管扩张"。

**处置（这一型专属）**：

1. **平卧**，抬高下肢
2. **补液**（口服或静脉）
3. 咖啡因可能短暂缓解（需医生指导）
4. **持续不缓解 → 需评估**（自发性低颅压、脑脊液漏、脱水）

#### ④ 紧张性头痛：肌肉"勒"住了

**感受**：**双侧、压迫感、像戴了一顶紧帽子或者被带子勒住**。**不搏动**。常伴**颈肩僵硬**。

**原理**：

```
颈肩和颅周肌肉（颞肌、枕下肌、上斜方肌）持续收缩
   ↓
局部血流下降 + 代谢物堆积
   ↓
肌肉和筋膜的痛觉感受器被激活
   ↓
压迫感、箍紧感
   ↓
长期 → 中枢敏化（痛阈下降）→ 越来越容易痛
```

**为什么"不搏动"**：因为它不是血管在扩张，是**肌肉在持续紧张**。**"搏动 vs 不搏动"是这两型最快的区分点。**

**处置（这一型专属）**：

1. **放松颈肩**（拉伸、按摩、热敷）
2. **调整姿势**——尤其长时间低头看屏幕
3. 降强度、保证睡眠
4. 长期：处理姿势和压力源，否则会反复

---

**四种机制的一句话说清**：

| 类型 | 谁在痛 | 一句话机制 |
|---|---|---|
| **运动性** | **血管壁** | 血压太高 → 脑血管被撑开 |
| **用力性** | **脑膜** | 憋气 → 颅内压瞬间升高 |
| **体位性** | **脑膜/颅神经** | 脑脊液不够 → 脑下沉被牵拉 |
| **紧张性** | **肌肉/筋膜** | 颈肩持续紧张 → 局部缺血 + 敏化 |

> 🚩 **头疼的红旗（这几条一定要记住）**：
> - **"雷击样"**——突然的、**一生中最剧烈**的头痛，几秒内达到顶峰 → 可能是**蛛网膜下腔出血**
> - 伴**发热 + 颈项僵硬** → 感染
> - 伴**单侧无力、言语不清、视物异常** → 卒中
> - **新发的、越来越重的**头痛 → 需评估
> - 头部外伤后出现 → 需评估脑震荡
>
> **"雷击样"这三个字，值得你专门记住。**

### 3.4 睡眠失常 + 静息心率偏高

**感受**（这两个经常一起出现）：

> 晚上**很累，但睡不着**。
> 或者睡着了**很浅、容易醒**。
> 早上一摸脉搏，**比平时快 5–10 下**。

**它们多半来自**：**恢复不足 / 交感神经过度激活**。

**机制**：

- **高强度训练后交感长时间激活**（尤其晚上训练）
- **核心体温升高**会推迟入睡
- **皮质醇节律改变**——正常应该"早上高、晚上低"，恢复不足时晚上降不下来
- **静息心率偏高**是交感占优的直接读数

> **这两个症状要一起看。** 单独一个可能是偶然，**"睡不着 + 心率高 + 表现下降"三件事同时出现**，就是明确的身体信号。

**处置**：

- 高强度训练安排在**睡前 3 小时以前**（当然，限于现实条件我们的晚训无法这样安排。如果你感觉到晚训长期影响了你的睡眠，我的建议是**以身体为重**。可以停训，也可以跟我聊一聊，降强度/改方式。）
- 训练后做放松、拉伸、缓慢呼吸
- 降温（洗温水澡、通风）

**预后**：

- **短期调整（几天）就能恢复** → 只是几天的高负荷，减量即可
- **连续多日不改善，且伴表现下降、情绪低落、食欲差** → 可能是**恢复不足 / 过度训练**，需要**主动减量一到两周**

> **一个实用的自查**：**每天早上醒来，躺着测一分钟脉搏，记下来。**
> 连续几天比基线高 5 次以上 → 身体在告诉你"还没恢复"。这比任何主观感觉都可靠。

## 本篇小结 · 下篇要讲什么

**把这一篇压缩成两句话：**

1. **"胸闷"和"头痛"各有四种来源**，而且它们的处置**方向相反**——心脏来源是"立刻停"，过度通气是"减慢呼气"，反流是"改吃饭时间"，紧张性是"松颈肩"。
2. **这两个系统的价值在于"分流"**：大多数是良性的，但良性的和致命的**感觉可以很像**。所以诊断靠的不是"疼得厉害不厉害"，而是**质感 + 伴随症状 + 与强度的关系**。

**下篇要讲剩下的四个系统：**

- **气道**：喘不上气、嗓子干痒
- **腹腔**：岔气、恶心、腹泻
- **体温与免疫**：发热、感冒能不能练
- **排废**：酱油尿

> 这四个系统的共同点是：**症状往往不那么吓人，所以最容易被忍着。**
> 但其中有一个，恰恰是**全篇唯一"看到就该立刻去医院"的**。
