```
出现不适
   │
   ├─ 说不清在哪、整个人不对劲、伴头晕恶心心慌 → 第二篇
   │
```

## 三、第一篇：工具篇（1 节，566 行）

**这一篇不讲任何具体的病，只讲一套"读法"。**

| 内容 | 讲什么 |
|---|---|
| **一、三类不适** | 可克服 / 需调整 / 需停止——**最难的是分清第一和第三** |
| **二、谁在写报告** | 伤害性感受器的分布：**皮肤、骨膜、关节囊、脂肪垫密 → 疼得准；肌肉、骨内部稀 → 疼得糊；软骨没有 → 坏了不痛** |
| **三、四个字段** | ① 感受（8 种）② 时间 ③ 位置 ④ 触发（7 种） |
| **四、三份样例** | DOMS / 肌肉拉伤 / 髌下脂肪垫 |
| **五、提问清单** | 五个问题，看医生时直接用 |
| **六、红旗速查** | 14 条"立刻停+就医" |

**其中"四个字段"是整套系列的语法**，后两篇只是往里填词：

| 字段 | 内容 |
|---|---|
| **① 感受** | 钝痛、刺痛、酸痛、胀痛、烧灼痛、搏动痛、绞痛、麻木 |
| **② 时间** | 即刻 / 数小时 / 24–72h / 数周–数月 / >3 月 |
| **③ 位置** | 指尖可指 / 一大片 / 沿一条线 / 说不清 |
| **④ 触发** | 牵拉、压痛、冲击震动、寒冷、启动、特定角度、静息夜间 |

## 四、第二篇：系统篇（3 节，共 1032 行）

### （上）供血与供能 · 280 行 —— 大脑"缺料"

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| **眼前发黑** | 一过性黑蒙（全脑低灌注）<br>⚠️ **单眼**发黑 → 颈动脉系统 TIA（卒中前兆） |
| **头晕** | ① **体位性低血压** ② **脱水**（血浆容量↓）<br>③ **低血糖** ④ **睡眠不足/中枢疲劳**<br>⑤ **感染前驱** ⑥ **贫血**<br>（※ 眩晕=前庭、平衡障碍=小脑/本体感觉，本篇另属） |
| **困顿** | 睡眠剥夺 / 感染前驱 / 贫血 / 过度训练 |
| **运动后头晕** | **运动后低血压**（肌肉泵骤停） |

### （中）指挥中枢 · 391 行 —— 节律乱了

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| **心悸** | 生理性心悸（交感兴奋）/ **心律失常** / **早搏** |
| **胸闷** | ① **心肌缺血**（牵涉痛）② **过度通气综合征**<br>③ **胃食管反流** ④ **呼吸肌疲劳** |
| **头疼** | ① **运动性头痛**（脑血管扩张）<br>② **用力性头痛**（瓦尔萨瓦→颅内压↑）<br>③ **体位性头痛**（低颅压）<br>④ **紧张性头痛**（颅周肌肉）<br>⚠️ 继发性：**蛛网膜下腔出血**等 |
| **睡眠失常 + 心率偏高** | **恢复不足 / 过度训练** |

### （下）肺、肚、体温、肾 · 361 行 —— 最容易忍的部分

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| **呼吸困难** | 呼吸肌疲劳 / **运动诱发支气管痉挛** / **声带功能障碍** / 贫血·心脏 |
| **咽痛、想咳** | **运动性气道脱水**（黏膜干燥） |
| **岔气** | **ETAP**（膈肌缺血痉挛 + 内脏韧带牵拉 + 壁层腹膜刺激） |
| **恶心** | **内脏缺血** + 5-HT + 化学感受器触发区 |
| **腹泻** | ① **缺血型**（肠道低灌注 + 反复再灌注）<br>② **受凉型**（冷刺激 → 自主神经反射） |
| **发热、感冒前驱** | **上呼吸道感染**（"颈以上"规则） |
| **酱油尿** | 🚩 **横纹肌溶解**（→ 急性肾损伤） |

## 五、第三篇：零件篇（6 节，共 2143 行）

### （一）僵 · 响 · 卡 · 360 行 —— 关节的"开机"和"运行噪音"

| 现象 | 具体是**什么病 / 什么异常** | 性质 |
|---|---|---|
| **关节僵硬** | A：滑液分布 + 组织黏弹性（**正常**）<br>B：**关节炎/滑膜炎活动期** | 两走向 |
| **关节空响** | **关节空化**（腔内气体气泡塌陷） | ✅ 正常 |
| **膝关节弹响** | ① **髌股弹响**（髌骨进出滑车沟）② **半月板弹响** ③ **肌腱弹响**（髂胫束/鹅足） | 多为正常 |
| **摩擦音** | 髌骨进出沟 / 软组织滑过骨突 / 气泡 / 半月板形变 / 脂肪垫 | 多为正常 |
| **卡顿** | **真性交锁**：半月板撕裂、游离体（机械性阻挡）<br>**假性交锁**：疼痛/肿胀导致的保护性不敢伸直 | 🚩 需查 |

### （二）烧 · 空 · 抽 · 麻 · 303 行 —— 肌肉和神经的极限

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| **灼烧** | **局部血流受限 + 代谢物堆积**（氢离子、无机磷酸、乳酸） |
| **发空** | **外周疲劳**：兴奋-收缩耦联效率下降（钙释放↓、肌丝敏感↓） |
| **抽筋** | ① **运动相关肌肉抽筋 EAMC**（神经反射失控：肌梭↑、腱器官抑制↓）<br>② **电解质相关**（长时间大量出汗） |
| **手麻 / 刺痛** | **神经压迫/牵拉/缺血**：尺神经、正中神经、胸廓出口、足背神经 |

### （三）撕 · 裂 · 282 行 —— 组织正在被拉坏

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| **肌肉撕裂状疼痛**（牵拉触发） | ① **轻度肌肉拉伤**（I 级）② **筋膜/肌腱交界受刺激**<br>③ **DOMS 期间的牵拉敏感** ④ **神经源性** |
| **足底撕裂状疼痛** | **足底筋膜病**（fasciosis，非单纯"炎"）<br>鉴别：跖间神经瘤、应力性骨折 |
| **各种剧痛** | **肌肉拉伤 I / II / III 级** |

### （四）歪 · 紧 · 262 行 —— 动作模式

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| **运动不平衡 + 肌肉紧张** | ① 疲劳性选择性募集 ② **肌力/肌耐力失衡**<br>③ **保护性肌肉紧张**（guarding）④ **动作模式问题** ⑤ 神经因素 |
| **膝外侧疼痛** | **髂胫束综合征（ITBS）**——**压迫**（非摩擦）<br>压的是外上髁下方**富含神经的脂肪垫** |

### （五）按下去才痛 · 340 行 —— 六个"点"的诊断

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| 骨上一点剧痛 + 冲击痛 | **骨应力性损伤**（骨应力反应 → 应力性骨折） |
| 有边界清楚的"包"，按包痛 | **滑囊炎**（⚠️ 红热肿+发烧 = **化脓性**，急症） |
| 整个关节胀、发热、晨僵 | **滑膜炎 / 关节积液** |
| 弥散钝痛，**活动到极限角度才痛** | **关节囊受刺激**（长期可致挛缩） |
| 明确外伤后骨面压痛 | **骨挫伤**（需较大外力） |
| 膝眼"辣辣的"，**伸膝到底/深蹲到底痛** | **髌下脂肪垫挤压** |

### （六）酸 · 肿 · 冲击 · 499 行 —— 运动后的三种"变化"

| 现象 | 具体是**什么病 / 什么异常** |
|---|---|
| **酸** | **DOMS**（延迟性肌肉酸痛）vs **肌肉拉伤** |
| **肿** | ① **关节积血**（几小时，血管破裂）<br>② **渗出液**（12–24h，滑膜炎/半月板/软骨）<br>③ **软组织水肿** ④ **骨髓水肿**（看不出肿） |
| **冲击痛** | **骨膜炎 / MTSS**（骨应力反应）vs **应力性骨折** |

**附：为什么女生更易骨应力性损伤**——能量可用性不足 → 月经紊乱 → 雌激素↓ → 骨密度↓（女性运动员三联征 / RED-S）

## 七、正常 vs 异常：跨篇分界汇总

**这一张表是全系列的"总开关"。**

| 现象 | 性质 | 分界线 |
|---|---|---|
| **关节空响** | ✅ 正常 | 不痛 |
| **膝弹响** | 多数正常 | **痛 / 卡 / 肿** |
| **摩擦音** | 多数正常 | **痛** |
| **灼烧** | ✅ 正常 | 力量训练可坚持；有氧要降强度 |
| **发空** | ✅ 正常但该停 | 刺激已耗尽 |
| **抽筋** | 可为正常 | **反复同一部位**要查 |
| **手麻** | 可正常也可异常 | **>1–2 小时不恢复 / 伴无力** |
| **关节僵硬** | 两种走向 | **3–5 分钟轻度活动**测试 |
| **卡顿** | 🚩 异常 | **需不需要用手掰开**（真/假交锁） |
| **撕裂痛** | 可正常（DOMS）也可异常（拉伤） | **当时就痛 vs 第二天才痛** |
| **冲击痛** | 🚩 异常 | 提示**骨**的问题 |
| **肿胀** | 🚩 异常 | **几小时（血）vs 12–24 小时（液）** |

## 八、红旗汇总（跨篇）

**出现任一条 → 停止运动，就医。**

| 类别 | 红旗 |
|---|---|
| **心肺** | 压榨样胸痛 + 放射 + 冷汗；心慌伴晕厥；与强度不匹配的极度气短；哮鸣；吸气困难 |
| **神经** | "雷击样"头痛；单眼发黑；单侧无力/言语不清；麻木 >1–2 小时不恢复 |
| **骨/关节** | 真性交锁；无法负重；明显畸形；固定一点剧痛 + 夜间痛 >2 周 |
| **肌肉** | 酱油色尿；剧痛 + 无力 + 肿胀；无法收缩 + 摸到凹陷 + 大面积淤青 |
| **感染/全身** | 发热 + 关节红热肿；夜间静息痛 + 体重下降；便血黑便 |
| **过敏** | 荨麻疹 + 呼吸困难 + 头晕 |
