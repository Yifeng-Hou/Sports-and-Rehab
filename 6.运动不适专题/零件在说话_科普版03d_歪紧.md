# 零件在说话（四）：歪 · 紧

### 运动不适 · 第三篇（四）——问题不在某一点，而在整个动作

> **接上一节。**
>
> 前面三节讲的都是"**某个结构**"：某个关节、某块肌肉、某条筋膜。它们有自己的位置、自己的感觉。
>
> 这一节讲的是另一类——**你说不清哪里有问题，但你感觉"整个动作不对"。**
>
> 一边紧、一边松；一边先累；跑起来像"一条腿在带另一条腿"。
> 这类问题的根源**往往不在那个"痛的地方"**，而在**动作模式**。

---

## 本节架构

```
  一 · 为什么这一类不一样
        前面：某个结构坏了
        这一节：整个动作在偏
              │
              ▼
  二 · 运动不平衡感 + 肌肉紧张
        ★ 五种可能，用"单侧测试"和"录像"来查
              │
              ▼
  三 · 膝外侧疼痛
        ★ 不是"摩擦"，是"压迫"
        髂胫束是一根"几乎拉不长的带子"
```

**一句话导读**：

> **这一节的两件事，都不是"忍一忍"能解决的。**
> 因为它们不是"过度使用"的结果，而是"一直用错"的结果——**不纠正模式，休息完还会回来。**

---

## 一、为什么这一类不一样

先看一个对比：

| | **前三节的问题** | **这一节的问题** |
|---|---|---|
| 根源 | **某个结构**承受了超出能力的东西 | **整个动作模式**让某个结构长期多干活 |
| 特点 | 位置清楚、有明确触发 | 位置模糊、两侧不对称 |
| 休息后 | 会好 | **会好，但一恢复训练就回来** |
| 解决方式 | 处理那个结构 | **改动作、改负荷** |

> **所以这一类最典型的特征是"反复"**：
> 休息两周好了，一上量又痛——**因为那个"让结构多干活"的模式一直没变。**

## 二、运动不平衡感与肌肉紧张

**感受**：

> **一侧"绷着不放松"**，摸上去比另一边硬。
>
> 动作**不对称**——深蹲时一边低一点，蛙跳朝一个方向偏（ps：审稿者作为带训人其实也有这个问题），弓步时一边更稳，背起时偏着起。
>
> 跑步时一条腿不自觉偏到侧面去了。跑起来有一种"**一边在带另一边**"的感觉。
> 一侧先累，而且总是同一侧。

### 五种可能的原因

| 机制 | 说明 |
|---|---|
| **疲劳导致的选择性募集** | 先累的一侧，能招募到的肌纤维减少，另一侧**代偿** → 暂时性不对称 |
| **肌力 / 肌耐力失衡** | 长期不对称 → **弱侧先崩** → 越练越偏 |
| **保护性肌肉紧张**（"防御性收缩"） | 附近有轻微损伤时，身体会**自动"锁住"**那一区域，防止你用它 |
| **动作模式问题** | 髋控制不足、足过度旋前、核心不稳 → 一侧负荷更大 |
| **神经因素** | 神经受刺激时，相应肌群的张力会改变 |

> **这五种你能自己分辨一部分**：如果只是"训练到后半段才出现"，可能第 1 、2种；**从一开始就有**，更可能是 2、4、5。

### 当场处置

- **降低强度，观察是否随疲劳缓解**
- **不要强行"练到两边一样"**——在疲劳状态下强行对称，容易伤到正在代偿的那一侧
- 如果一侧出现**疼痛**（不只是紧），按前面几节的原则处理

### 审稿人说点有的没的：
作为力学专业工科生，本人对人体的冗余自由度深有体会。

对于特定静止姿态，末端位姿固定，中间很多**冗余自由度**可以随意放置。对于动态平衡姿态（如跑步），姿态的平衡是个多解问题。

通过增大一处力量（静力训练时）/做功（运动时）来允许另一处发力（力或功）减弱，这种行为叫做**代偿**。——对静态平衡或动态平衡问题，其高维度的解空间带来了各种代偿姿势。**平板支撑抬臀塌腰、深蹲主要屈膝与主要屈髋的差别、仰卧交替抬腿腰拱起来……但是你的末端位姿不变，你确实在撑着、在蹲下、在抬腿**。

冗余自由度给人类活动带来极大的灵活性和便利，给予原始人类允许受伤的容错率。但正是这解的不唯一性，导致代偿成为可能（甚至主要部分）。而代偿是**正反馈系统**，**代偿-一边强一边弱-更容易代偿**，直到因轨迹偏移而出现**损伤**，或因为受力不均导致**磨损积累**。**我们却不知其根源**。

根据经验，代偿有多么花哨呢？**右可以代偿左，外可以代偿内，动态平衡中前可以代偿后，核心和远端可以相互代偿**，甚至出现**面部**代偿(bushi

短期代偿确实帮人度过难关，但**长期一个模式代偿，很可能肌力失衡、动作模式变异，出现损伤**。但也不需要杞人忧天天天想着这事，只不过在**有时发现肌力不均衡、运动不对称时，意念上多care一下弱侧。明显不平衡要警惕、评估、调整，可以寻求康复师帮助。出现运动损伤后，挖掘运动模式和力学机制上的原因。以及在康复过程中，不要一点不动，肌肉萎缩将触发新一种模式的代偿。**

说多了，话筒交给deepseek老师。

### 长期调整：五步系统查法

**这一条是本节最有操作价值的部分。** 因为"不平衡"这种东西，不查就是猜。

**第 1 步 · 拍视频**

- 从**正面**和**侧面**各拍一次深蹲、一次单腿蹲、一次跑步
- 看三件事：**膝盖有没有内扣、骨盆有没有歪、躯干有没有侧倾**

> **审稿人注：你怕是看不出来，不行咱就找康复师别将就**

**第 2 步 · 单侧测试**

同一个动作，左右各做一次，比较**次数和感受**：

| 测试 | 看什么 |
|---|---|
| **单腿蹲** | 哪边更不稳、哪边膝盖先内扣 |
| **单腿臀桥** | 哪边臀部先"没感觉"、哪边大腿后侧先抽 |
| **单腿提踵** | 哪边先做不到、哪边更晃 |

**第 3 步 · 优先练弱侧**

> **这是最反直觉、但最有效的一条**：
> 练单侧动作时，**从弱侧开始，做弱侧能完成的次数**，强侧只做同样的量。
>
> **不要"强侧多练几个补上"**——那会让差距更大。

**第 4 步 · 查足型和髋控制**

- **足型**：站立时足弓塌不塌？鞋底内侧磨损多不多？扁平足会让一侧负荷明显偏大
- **髋控制**：单腿站时骨盆会不会掉下去？（这是髋外展肌控制不足的典型表现）

**第 5 步 · 排除结构性问题**

- 明显的**腿长差异**、**脊柱侧弯** → 需要专业评估
- 这些不是"练一练就能改"的，需要针对性方案

> **一个提醒**：**轻微的不对称是正常的。** 人本来就不是完全对称的。
> 只有当**不对称在加重**、**伴随疼痛**、或**明显影响动作质量**时，才需要当成问题处理。（审稿人表示智齿）

## 三、膝外侧疼痛

**感受**：

> **膝盖外侧**，具体位置在**膝关节线上方两三厘米**（不是关节缝里）。
>
> **钝痛或烧灼痛**，有时是一片。
> **屈膝约 30° 的时候最明显**——所以**下坡、下楼**特别难受。
> 跑起来常常是"**跑了一段才开始痛**"，而不是一开始就痛。

### 先纠正一个流传很广的说法

> ⚠️ **不是"摩擦"，是"压迫"。**

```
髂胫束被"压"向股骨外上髁
   ↓
压迫它下方一层富含神经末梢的脂肪垫
   ↓
疼痛
```

### 髂胫束是什么

**一句话**：**大腿外侧一条很厚的结缔组织带**，从髋部一路连到膝盖下方（胫骨外侧）。

| 特点 | 说明 |
|---|---|
| 组成 | 主要是**筋膜和韧带样的组织**，不是肌肉 |
| 上游 | 连着**阔筋膜张肌**和**臀大肌** |
| **可延展性** | **极低**——它几乎拉不长 |

> 审稿人补充：**所以"拉伸髂胫束"拉的不是髂胫束**（它拉不动），而是它两端（或内嵌）的肌肉。降低其张力，从而降低髂胫束张力。只不过晚训之前的叫法一直是“髂胫束拉伸”，不改也罢。

### 为什么"屈膝 30°"最痛

压迫的峰值出现在**屈膝大约 20°–30°**——而这个角度，正好对应**跑步时足触地后不久**。

> **这解释了一个很多人困惑的现象**：
> **"为什么我跑一段才痛？"**
> 因为每一次触地都在那个角度上"压一下"，**累积若干次之后，脂肪垫才开始"抗议"**。

### 危险因素

| 因素 | 说明 |
|---|---|
| **髋内收 + 膝内旋**（动态膝外翻） | 跑步落地时膝盖往里塌 → 髂胫束张力更高 → 压迫更重 |
| **跑量突增** | 最常见的直接诱因 |
| **下坡** | 屈膝角度和冲击都更不利 |
| 臀中肌力量不足 | 无法控制髋内收 |
| 足过度旋前 | 向上传导，影响膝的旋转 |

### 当场处置

1. **停止或大幅降低强度**
2. **避免下坡、避免长时间屈膝 30° 的重复动作**
3. 局部冰敷（短期缓解）
4. 不要反复"按揉那个点"——压迫性疼痛按揉往往加重

### 长期调整：三条主线

**① 控制"髋内收 + 膝内旋"**

- 跑步时注意**膝盖方向**（不要让它往内塌）
- 提高步频、缩小步幅（减少单次冲击和屈膝幅度）
- 避免"交叉步"式跑姿
- 强化臀中肌（侧卧抬腿、蚌式、单腿臀桥）

**② 负荷管理（这是最关键的一条）**

> **髂胫束问题的核心是"压迫的次数"，而次数由跑量决定。**
> 很多人一好转就立刻回到原来的量，于是两周后又回来。
> **渐进增加，每周不超过原来的 10% 左右。**

**③ 不要指望"拉伸髂胫束"**

- 可以拉伸它两端的肌肉（阔筋膜张肌、臀大肌）
- 但**不要把它当成主要手段**

### 预后

- **多数在几周内明显改善**（配合负荷管理和髋控制训练）
- **复发率高**——因为跑量一回升，压迫次数就回升
- 反复发作、保守治疗 3 个月无改善 → 需要专科评估

## 本节小结

**把这一节压缩成三句话：**

1. **感觉或看出明显"不平衡"要评估、调整**：拍视频、做单侧测试、从弱侧开始练。
> 审稿人补充：你一般也感觉不出来，旁观者一般更容易看出来。
2. **膝外侧痛是"压迫"**——所以要减少压迫的次数和力量，而不是"把它揉开、拉开"。
3. **这两类问题的共同点是"会反复"**——因为它们不是"用多了"，是"**一直用错**"。休息只能治标，**改模式才治本**。

> **这一节的核心态度**：
> **前面几节教你怎么"处理一个点"，这一节教你怎么"看整个动作"。**
> 当同一个问题反复出现超过 2–3 周，就该从"点"退到"面"来看。
